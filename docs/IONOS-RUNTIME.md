# Correctifs du déploiement IONOS

Le démarrage conserve les adresses des comptes existants : il ne lance plus le correctif historique de courriel. Le lecteur Facebook intégré est autorisé par frame-src ; les autres protections CSP restent en place.

Ces modifications reproduisent les corrections de la copie IONOS. Elles ne modifient ni les mots de passe, ni les données, ni les variables privées. La base MySQL est isolée du réseau public.
