# Point d'entrée obligatoire pour agents autonomes

Ce dossier constitue la source de vérité visuelle et éditoriale de Synergie Dour.

## Ordre de lecture

1. `AGENT_INDEX.json`
2. `06_REGLES_ET_PROMPTS/brand-rules.json`
3. `06_REGLES_ET_PROMPTS/SYSTEM_PROMPT_AGENT_VISUEL.md`
4. `06_REGLES_ET_PROMPTS/GUIDE_EDITORIAL.md`
5. `06_REGLES_ET_PROMPTS/AUDIT_VISUELS_SOURCES.md`

## Règles non négociables

- Utiliser uniquement les fichiers officiels du dépôt.
- Ne jamais demander à une IA générative de recréer le logo.
- Ne jamais déformer, recoloriser, recadrer, tourner ou fusionner le logo.
- Générer les fonds sans texte ni logo, puis composer avec les fichiers officiels.
- Employer exactement : `Commerçants & indépendants réunis`.
- Garder JS-Innov.IA comme crédit optionnel, séparé de l'identité Synergie Dour.
- Ne jamais inventer de lieu, commerce, partenaire, personne, date, prix ou donnée locale.
- Appliquer un fonctionnement `fail-closed` : en cas de doute, bloquer et demander validation.
